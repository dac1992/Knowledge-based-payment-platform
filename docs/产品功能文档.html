02产品概述

2.1 产品定位

一句话定位 面向学术科研人群（研究生、高校教师、科研院所研究员、医学科研人员）的一站式知识付费与在线学习平台，以「学术课程 + 科研训练营 + 专家直播 + 学术社群」为核心，打通内容生产、交易转化、学习交付与用户运营全链路。

与泛知识付费平台（得到、千聊、知识星球）的差异在于：研脉以学术垂直深度为护城河，内容形态偏「体系化课程 + 强交付训练营」，用户画像高知、高客单、高复购，对内容专业性、数据准确性、学术合规性要求更高。

2.2 目标用户与角色

学学员（C 端）

研究生 / 博士生 / 青年科研人员 / 高校教师。诉求：技能提升（论文写作、统计分析、科研绘图）、考证、跟对导师。

师讲师（B/C 端）

高校教授、科研大牛、期刊编辑、行业专家。诉求：知识变现、个人 IP 打造、沉淀学术影响力。

商机构（B 端）

高校、科研院所、期刊社、学术会议主办方。诉求：批量采购课程、内部培训、学员管理。

2.3 核心价值主张

对象核心价值关键支撑能力
学员学得会、有人督、能被认可体系化课程 + 训练营督学 + 作业点评 + 结业证书 + 学术社群
讲师省心交付、持续变现零门槛建课工具 + 直播能力 + 分销裂变 + 自动结算 + 学员数据
平台内容资产沉淀、可规模化统一账号体系 + 数据中台 + 内容风控 + 多端分发

2.4 商业模式

  • 课程售卖：单课、专栏、训练营、会员订阅（月/季/年/永久）。
  • 直播付费：单场直播票、系列直播专栏、直播回放。
  • 会员体系：超级会员免费学 / 折扣学，提高复购与留存。
  • 分佣分销：学员分享员、达人推广、机构代理三级分销体系。
  • 机构采购：B 端批量授权、企业培训包、会议配套课程包。
  • 增值服务：1V1 论文辅导、专家咨询、查重/润色等学术服务撮合。

03市场与竞品分析

3.1 主流平台对比

平台定位核心优势主要短板对研脉的启示
小鹅通私域知识付费 SaaS多端（H5/小程序/APP/PC）一站式，营销工具 50+，AI Agent 矩阵年费高、配置复杂、内容非自营对标其「工具+营销+多端」，但要做得更轻、更垂直
千聊直播 + 训练营卖课直播成熟（连麦/打赏/课件同步），零门槛开播有抽成、私域沉淀弱训练营交付与直播互动要做深
知识星球付费社群社群粘性强、上手快、微信生态触达高无章节/课时/考试/作业，难做高溢价「圈子」模块补齐社群，但不作为主形态
得到精品内容品牌内容质量高、用户付费意愿强合作门槛高、自主运营空间小可做「研脉精选」自营精品栏目
知乎盐选信任型内容平台长尾搜索流量、专业信任背书无法直接卖课、链路长、抽成高用知乎/公众号做信任前置 + 内容引流
网易云课堂标准化课程卖场类目清晰、用户稳定个性化运营与私域能力弱标准化课程体系可参考，私域必须自建
荔枝微课轻量卖课工具操作简单、上线快系统扩展性弱、长期运营能力有限轻量版体验可借鉴（低门槛建课）

3.2 差异化定位

①学术垂直深耕

聚焦科研方法论、统计分析、论文写作、基金申报、医学临床科研等垂直品类，讲师需学术资质审核，建立专业壁垒。

②训练营强交付

不止卖课，更卖「结果」。以班级制、作业点评、1V1 反馈、结业答辩、成果认证构成强交付闭环。

③六端全场景

小程序轻触达、APP 深学习、PC 大屏办公学习、桌面客户端离线科研，覆盖学术人群全部使用场景。

④内容资产自主

自建平台、数据自主、零平台抽成，课程与用户数据完全归平台与讲师共有，可私有化沉淀。

全端共用一套统一用户中心（User Center），通过手机号 + 微信 UnionID 打通身份，实现「小程序下单 → APP 学习 → PC 端看回放 → 桌面端下载资料」的无缝衔接。

05角色与权限体系

5.1 角色定义

角色所属端核心权限范围
超级管理员后台全部功能、角色配置、系统设置、数据导出
运营经理后台课程审核、活动配置、首页装修、内容推荐

客服专员后台订单查询、退款工单、用户反馈、工单处理
内容审核员后台课程内容审核、评论审核、违规下架
讲师讲师端建课、上架申请、直播、学员管理、作业点评、查看本人收益

5.2 权限模型

采用 RBAC + 数据范围 模型：角色（Role）绑定菜单权限与操作权限（增/删/改/查/导出），数据范围控制可见数据（全部 / 本部门 / 本人 / 指定机构）。支持自定义角色与「数据权限矩阵」配置。

06功能模块详述

下文按端拆解功能模块。优先级标注：P1 必须有 P2 应该有 P3 可以有

6.1 管理后台 Web 端（平台运营中枢）

平台方使用的运营总控台，是所有资源、交易、数据的汇聚点。建议技术栈：React / Vue3 + Ant Design，响应式适配 1440px 及以上。

6.1.1 数据看板（Dashboard）

模块关键指标优先级
经营总览今日 GMV、成交订单数、客单价、退款率、付费用户数、环比同比P1
流量分析UV/PV、访问来源（搜索/分享/广告/私域）、漏斗转化（曝光→详情→下单→支付）P1
学习分析完课率、活跃学员、学习时长、作业提交率、结业率P2
商品分析各课程销量/营收/转化率排行、退课率P1
用户分析新增/活跃/流失、会员构成、RFM 分层P2

6.1.2 内容管理

  • 课程库：课程列表（SPU/SKU）、多条件筛选、批量上下架、排序、推荐位设置。
  • 课程审核：讲师提交 → 审核队列 → 通过/驳回（填写驳回原因）→ 上架；支持敏感词自动预检。
  • 内容形态管理：录播视频、音频、图文、专栏、训练营、直播、电子书、资料包。
  • 分类与标签：多级类目（学科 / 技能 / 场景）、标签体系、专题合集运营位。
  • 首页装修：可视化拖拽装修（轮播、金刚区、课程卡片、直播预告、合伙人位）。
  • 评论与问答：课程评论审核、精选、置顶、回复、举报处理。

6.1.3 交易与订单

模块功能点优先级
订单管理订单查询、详情、状态流转（待支付/已支付/已完成/已退款/已关闭）、备注、导出P1
退款管理退款申请工单、审批流、部分退款、退款原因统计、退课规则配置P1
发票管理开票申请、电子发票、纸质发票寄送、抬头管理P2
支付配置微信支付、支付宝、Apple 内购、余额、学习卡/兑换码P1
对账中心支付渠道对账单、账务流水、差异核对P2

6.1.4 用户与会员管理

  • 用户列表：多条件检索、用户画像、标签、学习记录、订单记录、备注、封禁/解封。
  • 标签体系：手动标签 + 规则标签（如「近 30 天未登录」），支持标签圈人做定向推送。
  • 会员卡管理：会员权益配置（免费课/折扣/专属内容/专属客服）、有效期、价格阶梯。
  • 积分体系：积分获取规则（学习/打卡/邀请）、积分商城、积分兑换。
  • 等级成长：成长值规则、会员等级、等级权益。

6.1.5 营销中心

券优惠券

满减券、折扣券、新人券、定向券；发放方式：手动/领券中心/活动赠送。

拼拼团 / 秒杀

2-5 人拼团、阶梯价；限时秒杀、限时折扣、打包套餐。

分分销体系

推广员/达人/机构三级分佣、佣金比例、海报生成、佣金结算与提现。

邀邀请裂变

邀请有礼、助力解锁、分享解锁、任务宝、社群裂变。

活活动管理

活动创建、报名、签到、抽奖、打卡挑战、积分任务。

推消息触达

站内信、短信、公众号模板消息、小程序订阅消息、APP 推送。

6.1.6 直播管理

  • 直播间创建、排期、预约、开播/停播、回放生成与剪辑。
  • 直播互动配置：弹幕、点赞、打赏、抽奖、问答、投票、红包、连麦。
  • 直播带货：挂载课程/商品、优惠券发放、限时秒杀。
  • 直播数据：在线人数、峰值、观看时长、转化订单、互动量。

6.1.7 社群 / 圈子管理

  • 圈子创建与审核，付费圈子定价与有效期。
  • 话题、问答、打卡、资料库、精华沉淀、成员管理（禁言/移出）。
  • 圈主（讲师）权限授予与内容风控。

6.1.8 财务结算

  • 平台营收报表、讲师分成结算（按课时/按销售额/固定稿酬）、分销佣金结算。
  • 提现申请审批、结算周期配置、结算单导出。
  • 税票与合规：代扣代缴、完税凭证。

6.1.9 内容安全与风控

  • 文本 / 图片 / 音视频自动审核（接入内容安全 API）+ 人工复审。
  • 敏感词库、违禁内容拦截、用户举报处理、违规下架与封号。
  • 版权保护：视频防录屏水印、防盗链、下载权限控制、DRM 加密。

6.1.10 系统设置

  • 账号与角色权限、操作日志审计。
  • 参数配置：平台名称、Logo、客服、协议（用户协议/隐私政策）、结算规则。
  • 第三方对接：微信小程序/公众号/开放平台、支付、短信、IM、CDN、AI 能力。

6.2 讲师操作 Web 端（讲师工作台）

讲师自助经营阵地，核心目标是「让讲师 30 分钟开出一门课」。与后台管理端分离部署，界面更聚焦、更轻量。

6.2.1 入驻与认证

  • 讲师入驻申请：实名认证（身份证）、学术资质认证（学历/职称/任职机构/代表作）、人脸核身。
  • 签约协议在线签署、结算账户绑定、分成比例确认。
  • 审核进度查询与驳回原因说明。

6.2.2 课程创建与管理

课程结构课程 → 章节 → 课时；支持试看、免费课时、章节目录拖拽排序
素材上传视频/音频拖拽上传、断点续传、转码进度、封面裁剪、字幕上传

6.2.3 直播与教务

  • 开播工具：浏览器开播（摄像头/屏幕共享/PPT 演示）+ 推流码开播（OBS）。
  • 班级管理：建班、招生、分班、学员名单、考勤、进度跟踪。
  • 作业批改：收作业、批改、评分、点评、优秀作业展示。
  • 答疑：课程问答、圈子答疑、私信回复。
  • 通知：向班级/学员群发通知、开课提醒。

6.2.4 数据与收益

  • 课程数据：曝光、详情访客、下单转化、销量、营收、完课率、评分。
  • 学员数据：新增学员、地域分布、学习时长、活跃度。
  • 收益中心：可提现余额、累计收益、结算明细、提现申请、分成账单。
  • 分销管理：我的推广员、佣金比例、佣金明细。

6.6 用户 PC 本地端（Windows / Mac 桌面客户端）

07核心业务流程

7.1 课程上架流程

讲师入驻认证→ 创建课程→ 上传内容/设置价格→ 提交审核→ 平台审核→ 通过上架 / 驳回修改→ 运营推荐位配置

7.2 购买支付流程

浏览/搜索→ 课程详情→ 加入购物车/立即购买→ 选择优惠券/会员价→ 提交订单→ 支付→ 支付回调→ 开通权益+消息通知
异常处理支付超时自动关闭订单；支付成功但回调延迟时，提供主动查询补偿；重复支付自动退款；退款走审批工单。

7.3 学习交付流程

开通学习权限→ 加入班级/学习计划→ 观看课时→ 完成作业→ 讲师点评→ 结业考核→ 颁发证书

7.4 分销推广流程

学员申请成为推广员→ 生成专属海报/链接→ 好友下单→ 订单归因（锁定关系）→ 佣金入账（T+N）→ 提现审核→ 打款

08会员与增长体系

★超级会员

月/季/年/永久卡；权益：精选课程免费学、购课折扣、专属内容、专属客服、优先答疑。设计目的：提高复购与留存，带动长期 LTV。

积积分体系

学习、打卡、分享、邀请、评价获得积分；积分兑课、兑券、兑实物。设计目的：引导高频行为，形成「学习-奖励-复购」闭环。

★成长等级

成长值由学习时长、完课数、互动累积；等级解锁专属权益与身份标识。设计目的：荣誉感与身份认同。

社社群裂变

邀请有礼、助力解锁、拼团、任务宝、海报分销。设计目的：低成本获客，社交关系链传播。

10内容安全与合规

  • 资质合规：ICP 备案、增值电信业务经营许可证（ICP 许可）、网络文化经营许可证（如需）、广播电视节目制作许可（如涉自制视频）。
  • 内容审核：接入内容安全能力，机审 + 人审双保险，覆盖文本、图片、音视频、评论。
  • 知识产权：讲师上传内容需承诺原创/已获授权；平台对盗版内容快速下架处理（通知-删除机制）。
  • 用户协议：用户服务协议、隐私政策、未成年人保护、退费规则公示。
  • 数据合规：个人信息保护法（PIPL）合规，明示收集范围、获取授权、支持注销与数据导出。
  • 支付合规：iOS 虚拟商品走 Apple 内购；微信/支付宝商户资质齐全。
  • 版权保护：视频动态水印（用户 ID + 时间）、防盗链、下载加密、离线内容一机一码。
