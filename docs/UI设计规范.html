01设计概述与原则

1.1 设计目标

研脉学术的用户群体以高知科研人群为主，他们对界面的专业感、信息密度、阅读舒适度要求高于普通消费级产品。设计系统需在「学术严谨」与「现代易用」之间取得平衡。

1.2 五大设计原则

① 学术专业

以沉稳的学术蓝为主色，克制的色彩使用，传递专业与可信赖感。避免过度花哨的视觉噪音。

② 内容优先

界面为内容让路。清晰的信息层级、充足留白、高可读的正文排版，让学习者专注内容本身。

③ 高效清晰

操作路径短、反馈即时、状态明确。后台与工作台强调效率与信息密度，减少无效点击。

④ 多端一致

六端共享同一套设计语言（色彩、字阶、组件语义），差异仅体现在布局与交互手势上。

⑤ 情感温度

在严谨之外，用金色点缀、友好的空状态与成就激励（勋章、证书、打卡），给予学习者正向反馈与陪伴感。

02品牌基础

2.1 品牌调性

维度关键词视觉转译
气质专业 · 严谨 · 可信学术蓝主色、规整栅格、克制的留白

效率清晰 · 高效 · 顺畅明确层级、即时反馈、流畅动效

2.2 Logo 使用规范

  • 安全边距：Logo 四周留白不小于其高度的 1/2。
  • 最小尺寸：PC 端最小高度 24px；小程序/APP 图标位不小于 32px。
  • 颜色版本：彩色版（默认）、白色反白版（深色底）、单色版（印刷/水印）。
  • 禁止：拉伸变形、加描边、换色、加投影、低对比度背景上使用彩色版。

4.3 字重规范

  • 中文尽量避免 500 字重（部分系统渲染为虚拟加粗，效果差），使用 400 / 600 / 700 三档。
  • 标题用 600–700，正文 400，强调用 600 或加主色，按钮文字 600。
  • 金额数字使用 700–800，配合等宽数字（font-variant-numeric: tabular-nums）保证对齐。

06图标与插画

6.1 图标规范

  • 风格：线性（stroke）为主，线宽 1.5–2px，圆角端点；功能图标可配面性（filled）用于选中态。
  • 尺寸：16 / 20 / 24 / 32px 四档，常用 24px。
  • 颜色：继承文字颜色（currentColor），可配主色/中性色。
  • 图标库建议：统一使用一套（如 Lucide / IconPark / 自建），禁止混用多套图标风格。
  • 语义一致：同一含义在全端使用同一图标（如「学习」全端用同一个播放/书本图标）。

6.2 插画风格

  • 用于空状态、引导页、成就页、错误页。
  • 风格：扁平 + 微立体，主色系（蓝金），简洁几何，体现学术元素（书籍、显微镜、数据图表、学位帽）。
  • 统一视角与光感，避免风格割裂；插画内文字不参与排版。

09交互与动效

9.1 动效原则

  • 克制：动效服务于理解与反馈，不做无意义炫技。时长 150–300ms。
  • 有意义：页面切换、元素进出、状态变化才有动效。
  • 可中断：动画可被用户操作打断，不阻塞交互。

9.2 缓动曲线与时长

场景时长缓动
悬停 / 按下反馈150msease-out
弹窗 / 抽屉进出250mscubic-bezier(0.4,0,0.2,1)
页面切换300msease-in-out
加载骨架屏1200ms 循环linear 呼吸

9.3 状态反馈

  • 所有可点击元素必须有 悬停 / 按下 反馈；异步操作必须有 加载态。
  • 操作结果用 Message（轻提示）/ Notification（通知）反馈，成功用绿色、失败用红色。
  • 危险操作（删除、退款）必须二次确认。

10深色模式

深色模式作为可选主题（桌面客户端与 APP 优先支持），采用「深灰蓝」而非纯黑，降低长时间阅读的视觉疲劳。

11可访问性（Accessibility）

  • 对比度：正文文字与背景对比度 ≥ 4.5:1；大号文字 ≥ 3:1。
  • 字号：正文不小于 14px（移动端），支持系统字体缩放不影响布局。
  • 色彩：不单靠颜色传递信息（如错误状态同时有图标 + 文案）。
  • 键盘：PC 端支持 Tab 导航、焦点可见（focus outline）、快捷键操作。
  • 热区：触控目标 ≥ 44×44px；元素间距充足，防误触。
  • 动效：尊重 prefers-reduced-motion，可关闭非必要动画。
  • 读屏：图片提供 alt、按钮提供 aria-label、表单提供 label 关联。

12设计交付与命名规范

12.1 设计稿交付

  • 使用设计工具（Figma / MasterGo）建立组件库与变量（Variables），颜色/字号/间距全部走 Token。
  • 交付内容：页面设计稿 + 组件库 + 交互标注 + 切图资源（SVG 图标）+ 多端适配说明。
  • 设计方案需覆盖：默认态、空状态、加载态、错误态、无权限态。
